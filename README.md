# Camera-only localization of a race car (Constructor Labs, National AI Hackathon 2026)

Estimates the pose of `constructor0/base_link` in the track frame `map` — x, y, yaw — from the 7 car cameras at
10 Hz, causally (a pose at time t uses only frames with stamp ≤ t), with the first GT pose as the only GT input.

**Method (v2, frozen — see `v2/FROZEN.txt`):** a 3D keyframe map is built once from the training laps
(SuperPoint features triangulated with GT poses). At run time an EKF on the track predicts the pose from the
whitelisted car-state fields (`car_state.py`); corrections come from matching the current 7-camera set against the
map keyframe nearest to the prediction (SuperPoint + guided matching on GPU) and a robust multi-camera
Gauss–Newton pose solve. If the filter is uncertain, it falls back to DINOv2 retrieval + LightGlue (v1).
Details: `report/method.html`.

## Setup

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cu126
```
Put the dataset (not included in this repo, see Licence) at
`data/c0_2026-10-13_22-53-42_camloc/` (mcap + `tools/`).

## Pipeline

```bash
MCAP=data/c0_2026-10-13_22-53-42_camloc/c0_2026-10-13_22-53-42_camloc_0.mcap
# 1. light data + GT
python3 export_lite.py $MCAP export
python3 data/c0_2026-10-13_22-53-42_camloc/tools/extract_gt.py $MCAP gt.csv
python3 analysis/analyze.py                 # laps.csv, centerline.npz
# 2. map (training-time, uses GT of development laps only)
python3 extract_frames.py $MCAP frames      # half-res frames
python3 make_masks.py                       # car-body masks
python3 db_build.py                         # features/db_<cam>.npz
python3 global_desc.py                      # features/global_<cam>.npy (DINOv2)
python3 v2/build_model.py                   # v2/model/
# 3. run the localizer on a window (start, length in s from the bag start) and score it
python3 sim/simulate.py --gt gt.csv --mcap $MCAP --localizer v2/my_loc_v2.py:Localizer \
        --speed 1 --start-s 523.4 --max-s 110.6 --no-gui --tag v2_val_K3
```
Output: `sim/runs/<tag>/pred.csv` (`timestamp_ns,x,y,yaw`) and `evaluate.txt`.
Validation runs as in the table: `v2/run_val.sh`, `v2/run_cluster.sh`.

## Layout

| path | content |
|---|---|
| `v2/` | final localizer (`my_loc_v2.py`), model artefacts (`model/`), run scripts, results |
| `sim/` | real-time simulator / scorer (`simulate.py`), v1 localizer (`my_loc.py`) |
| `localize.py`, `track_filter.py`, `camera_model.py`, `car_state.py` | v1 localization, track EKF, camera model, allowed car-state fields |
| `db_build.py`, `global_desc.py`, `extract_frames.py`, `make_masks.py` | map building |
| `analysis/` | data analysis (plots, laps, centerline) |
| `results/` | early experiments (`evaluate.py` outputs) |
| `report/` | HTML report |
